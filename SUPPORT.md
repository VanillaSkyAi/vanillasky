# Support

VanillaSky is an early open-source video-chat application with best-effort
support. There is no guaranteed response time.

For a reproducible problem, search the docs and existing issues, then open an
[issue](https://github.com/VanillaSkyAi/video/issues) with the application commit,
Node/npm versions, browser, configured provider/model names, reproduction steps,
and expected versus observed behavior. Include only redacted diagnostics.
Never include provider keys, customer data or private media URLs.

This repository develops the runnable application. npm package versions through
0.11.3 remain available for existing users, but new development does not publish
package updates or maintain a generated starter. Use the matching historical
Git tag for a published package's source and documentation.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) and use private reporting.
A public issue does not create a response-time or resolution commitment.
